# PCMN — исследовательский прототип 0.1

Это **не обученная нейросеть уровня LLM** и **не доказанная замена трансформеров**. Это запускаемая лабораторная заготовка с понятными контрактами и тестами: причинное рекуррентное ядро, параллельное ассоциативное сканирование, вероятностный прогноз, линейная структурная причинная модель, «зеркальное» контрастивное сопоставление наблюдения/действия, кодировщики и декодеры текста, аудио, изображения и видео.

Обработка аудио/изображений/видео в версии 0.1 — это преобразование массивов в латентные последовательности и обратно. Генераторы **не обучены**, высококачественный синтез речи/фото/видео и универсальные причинные выводы отсутствуют. Никакая реальная задержка или качество в сравнении с трансформером не гарантируются.

## Запуск Windows PowerShell

```powershell
cd PCMN_prototype
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m scripts.train_toy --steps 80
python -m scripts.benchmark --length 64
```

Вместо `python -m scripts...` допустимо `python scripts/train_toy.py` только при установленном пакете `pip install -e .`; поэтому рекомендуемый запуск из корня — с `-m`.

Для Tesla P100 (Pascal / sm_60) нужны сборки PyTorch, в которых эта архитектура ещё поддерживается. По состоянию на 2026-10 полезно проверять линейку CUDA 12.6 и поддерживаемую версию PyTorch (например, `torch==2.12.0` из `https://download.pytorch.org/whl/cu126`). CUDA 13.x не поддерживает Pascal. Совместимость сборки с RTX 4060 + Tesla P100 проверяйте `torch.cuda.get_device_capability(i)`. На Windows вместе с Pascal не все новые библиотеки fused SSM/FlashAttention подходят — этот прототип не использует пользовательские CUDA kernels и может выполняться на CPU.

Пример установки PyTorch CUDA 12.6 (после создания venv, вместо обычной установки Torch):

```powershell
pip install torch==2.12.0 --index-url https://download.pytorch.org/whl/cu126
pip install -e . --no-deps
python -m unittest discover -s tests -v
```

## Структура

- `ARCHITECTURE_RU.md` — математическая спецификация, план обучения и сравнения.
- `pcmn/model.py` — рекуррентное ядро и текстовая языковая модель.
- `pcmn/multimodal.py` — четыре входных модальности, свёрточные патч-кодеки и выходные головы, включая демонстрационные API `synthesize` и `generate_text`.
- `pcmn/probability.py` — гауссов прогноз среднего и дисперсии.
- `pcmn/causal.py` — структурная линейная причинная модель с явными вмешательствами `do(X=x)`.
- `pcmn/mirror.py` — парное обучение наблюдение ↔ действие через симметричную InfoNCE-потерю.
- `scripts/train_toy.py` — игрушечное обучение прогнозу простого следующего токена.
- `scripts/benchmark.py` — локальная оценка времени **без вывода о превосходстве**.
- `tests/test_core.py` — согласованность параллельного и последовательного сканирования, градиенты, форматы всех модальностей, вмешательства.

## Основная математика

Аффинная рекурсия: `h_t = a_t * h_(t-1) + b_t`, где `a_t = sigmoid(W_a x_t + bias)`, `b_t=(1-a_t) tanh(W_b x_t)`.

Парное объединение двух последовательных переходов:
`(a2, b2) ∘ (a1, b1) = (a2*a1, b2 + a2*b1)`.

Оператор ассоциативен, поэтому временные шаги можно объединять в дерево (`log2(T)` синхронных этапов). Это обеспечивает параллельное обучение и константный объём рекуррентного состояния для пошагового декодирования. Реализация PyTorch в учебном варианте имеет `O(T log T)` работы и дополнительные аллокации; для настоящего ускорения необходим блочный fused scan / CUDA kernel, аналогичный SSD.

### Приоритетные следующие этапы

1. Обучение на реальных текстовых датасетах с базовой проверкой perplexity, длины контекста и recall.
2. Замена Python/PyTorch reference scan на эффективный chunked scan и специальные CUDA/Triton ядра с запасным вариантом для Pascal.
3. Сравнение с Transformer, Mamba-3 и RWKV-7 при равной ёмкости, токенах и бюджете.
4. Обучение мультимодальных кодеков и выравниванию латентных пространств на лицензированных парных данных; затем выходных генеративных декодеров.
5. Прогноз `p(z_(t+1) | z_t, do(a_t))` и отдельная проверка различения корреляции от интервенции на симуляторах.
6. Блочный неавторегрессионный декодер текста, измерение скорости **и** согласованности выходных блоков.

## Основное ограничение

Чистая state-space архитектура способна проиграть Transformer на точном восстановлении редких фактов из очень длинного контекста; поэтому в следующей версии нужна адресуемая эпизодическая память с retrieval и возможностью длинного хранения. `do()` корректен лишь для заданной структурной модели, он не доказывает, что причинная структура выучена из данных.
