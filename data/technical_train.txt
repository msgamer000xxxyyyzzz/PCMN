# PCMN — исследовательская архитектура, черновая спецификация 0.1

Статус: рабочая гипотеза и минимальный прототип. Нет претензий на фундаментальную новизну конкретного математического оператора или на превосходство Transformer, RWKV, Mamba.

## 1. Цели и критерии

Требование R1: максимальная параллельность обучения / обработки длинных входов при низкой памяти.

Требование R2: быстрый streaming inference с фиксированным локальным recurrent state и отдельной адресуемой памятью.

Требование R3: причинное прогнозирование мира при условии вмешательств, а не только прогноз следующего токена.

Требование R4: целостные представления текста, аудио, видео и изображений, включая генеративные выходы.

Требование R5: возможность проверять происхождение ответа и вычисления с помощью внешних математических решателей.

Требование R6: корректно калиброванная неопределённость и явная проверка гипотез.

## 2. Вычислительное ядро и временная сложность

Пусть x_t в R^d, h_t в R^d:

```
a_t = sigmoid(W_a * norm(x_t) + b_a)
b_t = (1 - a_t) * tanh(W_b * norm(x_t))
h_t = a_t ⊙ h_(t-1) + b_t
y_t = W_o h_t + x_t
```

Обозначим аффинный переход (A,b), где A диагонален. Композиция:

```
(A2,b2) o (A1,b1) = (A2*A1, b2+A2*b1)
```

Она ассоциативна: можно построить параллельный префиксный scan. Демонстрационная реализация — O(T log T) работы и O(log T) синхронных этапов. Оптимизированный chunked scan должен приближаться к O(T) работы в заданном объёме состояний.

**Проблема:** конечномерная рекурсия сама по себе может плохо воспроизводить поиск точного факта из громадного контекста. Нужны долговременная память, внешние индексированные таблицы и отдельные тесты на точный поиск.

## 3. Вероятностный слой

```
p(z_next | z_current, action, observation)
posterior ∝ likelihood × prior
H(P) = - Σ_i p_i log(p_i)
```

Практические компоненты: Gaussian NLL для непрерывных переменных, категорический cross-entropy для токенов, вероятностные ансамбли для эпистемической неопределённости, тесты calibration/ECE/Brier, вывод с частичной наблюдаемостью / байесовские фильтры.

Один `sigma`-выход (в текущем коде) не есть полная байесовская нейросеть. Он даёт базовую **алеаторную**, зависящую от данных неопределённость.

## 4. Причинный блок

Реальные причинные механизмы в общем случае **не восстанавливаются однозначно из одних наблюдений**. Предлагаемая причинная модель мира:

```
z_(t+1) = f_theta(z_t, do(a_t), eps_t)
p(z_(t+1) | z_t, do(a_t))
```

Следует собирать интервенционные данные (агент изменяет действия в симуляции), фиксировать переменные и конфаундеры, тестировать переносимость между средами. `OrderedLinearSCM` в коде демонстрирует корректную для заданного графа семантику `do(X=x)`, но сам по себе не обучен реальной физике.

## 5. «Зеркальные нейроны» как алгоритм

```
z_obs = normalize(E_observation(trajectory))
z_act = normalize(E_action(action_trajectory))
L_mirror = symmetric_InfoNCE(z_obs, z_act)
```

На парных демонстрациях движение наблюдаемого объекта кодируется так, чтобы модели было легче выбрать/объяснить соответствующее действие. Дополнительно учить inverse dynamics (из состояний предсказать действие), forward dynamics (из состояния и действия предсказать результат), imitation и alignment across embodiments. Это инженерная аналогия «зеркальной» функции, а не прямое воспроизведение биологических зеркальных нейронов.

## 6. Математика и логика

Выделить специализированные головы / инструменты для символьной алгебры, численных методов, теории графов, оптимизации, вероятностного программирования, задач удовлетворения ограничений, дифференциальных уравнений, доказательств и контроля единиц измерения. Не обучать единую плотную сеть механически «всей математике» — отбирать методы под конкретную задачу.

## 7. Память

- Локальное рекуррентное состояние: потоковая память O(d) на слой, не растущая с контекстом (в этой версии).
- Эпизодическая адресуемая память: retrieval с сохранением источника, даты, идентификаторов сцены.
- Семантическая память: устойчивые знания, проверка фактов и обновления.
- Рабочее пространство: несколько конкурирующих гипотез и маршрутизатор, не обязательно биологическая модель сознания.

## 8. Мультимодальность

**Вход:** текст токены; аудио frames или codec-токены со временем; изображения пространственные patches; видео и синхронизированный звук как пространственно-временные patches. Обязательны индексы времени и согласование разных частот.

**Выход:** отдельно декодеры слов/подслов; акустических codec-токенов+вокодер; latent diffusion/flow для изображений; spatial-temporal decoder и аудиосинхронизация для видео. В версии 0.1 только простые не обученные обратные ConvTranspose-кодеки; качество генерации не заявлено.

## 9. Параллелизм

- Вход и обучение: по батчам, каналам, experts, модальностям и последовательностям; параллельный scan.
- Вывод: autoregressive streaming требует последовательной зависимости между токенами.
- Исследовать blockwise masked generation и/или draft-and-verify, измеряя и фактическую скорость и качество, а не только FLOPs.
- Модель распределяется по разным GPU только когда выигрыш превышает копирование активаций по PCIe.

## 10. Функции потерь (план)

```
L_total = w_text * CE(text)
        + w_recon * [L_image + L_audio + L_video]
        + w_align * InfoNCE(align_pairs)
        + w_dynamics * NLL(next_latent)
        + w_causal * L_interventions
        + w_consistency * L_world_consistency
```

Весовые коэффициенты валидируются; цель обучения надо вводить постепенно и проверять конфликты градиентов.

## 11. Протокол честной проверки

Одинаковое количество параметров или compute-equivalent сравнение, фиксированные токены и аппаратные ресурсы, одинаковые данные / токенизатор / контекстные окна там, где возможно. Сравнить:

- Качество: validation perplexity / NLL, retrieval / associative recall, long context, инструкции, математика, код, video QA, audio tasks, image metrics, причинные задачи на вмешательства.
- Скорость: latency first token, tokens/sec в generation, training tokens/sec, peak VRAM и RAM, энергопотребление.
- Scaling: T=512 ... 65 536, batch=1 ... 64, GPU vs CPU, 1/2/3 GPU, разные precision / kernels.
- Robustness: перенос на новые причинные среды, out-of-distribution, контрфактические тесты.
- Статистика: хотя бы несколько random seeds и доверительные интервалы.

Важный принцип: исключить качество pretraining tokenizer и размер датасета как незаметный конфаундер. Демонстрационный benchmark текущего архива не является научной оценкой.

## 12. Последовательность реализации

P0: пройти корректность scan, градиенты, эквивалентность streaming и batch, обучение toy. **Готово в 0.1.**

P1: реальные обучающие текстовые данные, измерения против Transformer + RWKV + Mamba (выбор соответствующих checkpoints).

P2: chunked CUDA scan и оптимизация памяти, с fallback PyTorch для Pascal.

P3: memory retrieval и длинные контексты.

P4: энкодер аудио+изображения+видео, joint representation training, синхронизация по времени.

P5: probabilistic world model + каузальные симуляторы и активное вмешательство.

P6: зеркальное observation-action learning и динамика движения.

P7: текстовое блочное декодирование / мультимодальная генерация, distillation/pretraining, масштабирование.
