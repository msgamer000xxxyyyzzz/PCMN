# PCMN v0.4: объективный статус задач T01–T10

- **T01 частично:** исходники C++ CPU scan, CMake сборка Linux и MSVC, проверка эквивалентности, CPU замер. Полноценного C++ inference без PyTorch и fused SIMD всех слоёв нет.
- **T02 частично:** PyTorch CUDA/FP16 путь из v0.3, новые CUDA scan исходники только для inference, послойный sharding. Тестов на реальных GPU не выполнено (нет GPU), backprop через CUDA scan не реализован.
- **T03 реализован экспериментально:** четыре и более конфигурируемых динамических key-value слота, exact chunk/step tests; не обучена память надёжного long recall.
- **T04 частично:** курация JSONL по allowlist лицензий, SHA256, split, отчёты, старый binary pipeline. Нет промышленного много-терабайтного пайплайна и near-dedup, BPE подготовка из JSONL требует доработки.
- **T05 частично:** 30 шагов маленького v0.4 (149700), 1 шаг модели 30,289,748 на CPU, сохранение весов и checkpoint. Полное предобучение 30M/100M на масштабном корпусе НЕ проведено.
- **T06 частично:** точные генераторы и оценка арифметики, простого do(SCM), переменных, AST для кода. Измеренная точность 0/8, не зрелое рассуждение.
- **T07 частично:** SFT на 80 маленьких синтетических тренировочных примерах, 12 шагов, контрольная выборка. Нет обученной coding LLM и реального code benchmark.
- **T08 частично:** read-only файловые инструменты, безопасный калькулятор, добавлены host approval для записи и запуска тестов. Нет криптографической песочницы/полноценного умного агента.
- **T09 реализован стартовый bench:** 37 автоматических тестов и CPU сравнение checkpoint'ов на одинаковых входах, но без сопоставимого бюджета обучения. Работают отчёты JSON.
- **T10 частично:** локальный `/v1/models`, `/v1/completions`, `/v1/chat/completions`, SSE. Не полноценный OpenAI API и не production server.
