Все три замера: последовательность 64 декодируемых токена, batch=1, 7 повторов, median, без prefill и токенизации. Эти цифры могут отличаться на других CPU; сравнения не независимый конкурентный бенчмарк llama.cpp/Transformer.

## Мини-обучение и качество

- 2 273 480 параметров, 12 шагов, byte tokenizer, крошечный корпус.
- Validation NLL: **5.096528 → 2.680273**, validation PPL: 163.45 → 14.59.
- Восемь синтетических задач на математику, логику, причинность и код: **0/8**.
- Пример вывода данной модели содержит некорректные UTF-8 фрагменты; это не готовая языковая модель.

## Поиск памяти

- 12/12 на 2048, 12/12 на 8192, 12/12 на 32768 синтетических предложениях.
- Это **lexical hit@3**, маркер уникален, без LLM inference, оценка на искусственных данных, не benchmark семантического понимания.

## Состояние окружения

- PyTorch CPU 2.10.0 (Python 3.13); NVIDIA GPU/CUDA нет. Проверки на P100 не проводились.
- Опциональная библиотека `tokenizers` отсутствует (установка через pip недоступна из-за отсутствия сети). В итоге полноценный BPE end-to-end в данной среде не тестировался.
- Нативный CPU C++ scan собран CMake; 45 unit tests passed.

## Следующая проверяемая цель

Собрать CUDA extension и запустить `scripts.build_cuda --arch 6.0` на Tesla P100, выполнить CPU throughput на EPYC7352; построить лицензированный многоязычный BPE корпус, обучить 30M на значимом количестве токенов, сравнить с baseline при равных бюджетах. Текущая демонстрация не свидетельствует об уровне современных LLM.
